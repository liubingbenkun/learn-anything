# Research and Source Management

## Research map

Before writing a course, collect enough evidence to answer:

- What is the field's object of study?
- What problems organize the field?
- Which prerequisite concepts explain those problems?
- Which discoveries changed what researchers believed or could do?
- Which methods dominate today, and why?
- What can the field accomplish in practice?
- Which questions remain open or disputed?

Do not turn every answer into a lesson. Use the map to select a coherent conceptual spine.

## Source hierarchy

Prefer, in order appropriate to the claim:

1. original papers for discoveries, methods, and experimental results;
2. official documentation for tools, standards, and current behavior;
3. authoritative reviews or textbooks for synthesis and history;
4. course materials from credible institutions for pedagogical framing;
5. secondary explainers only when they add unusually clear intuition.

Use multiple viewpoints for disputed topics. Distinguish established knowledge, reasonable interpretation, and speculation.

## Source portfolio

For a comprehensive course, aim for a compact portfolio rather than a bibliography dump:

- one or two strong overview sources;
- landmark sources for major historical transitions;
- representative original papers for core method families;
- recent primary sources for the current frontier;
- counterexamples or alternative schools where debate matters.

For quick-start mode, use fewer sources but keep an overview, one representative method source, and one current reality check.

## Currentness and verification

Browse whenever there is a meaningful chance the fact has changed, including recent achievements, software, standards, regulations, active researchers, or field consensus. Verify titles, authors, dates, identifiers, and major numeric claims. Link claims near their supporting source.

Do not describe a paper's detailed method or results from memory when the source can be opened. If only an abstract is available, limit the description accordingly.

## Downloading and local libraries

When the user wants local materials or an ongoing course benefits from them:

1. prefer publisher open-access PDFs, PubMed Central, author repositories, institutional repositories, or official preprints;
2. do not bypass paywalls or access controls;
3. use stable, descriptive filenames: `FirstAuthor_year_short_title.pdf`;
4. verify the file header begins with `%PDF` and check that file size is plausible;
5. remove HTML error pages saved with a `.pdf` extension;
6. record failed or paywalled items as `manual retrieval needed`;
7. keep a source index with citation, DOI/URL, local path, access status, and course purpose.

If a large download, subscription login, or external authorization is needed, tell the user exactly what is missing.

## Learning notes

For a persistent course, keep polished notes distinct from raw research:

- course route and current position;
- lesson story line and core concepts;
- representative examples and diagrams;
- learner's substantive questions and corrected misconceptions;
- source cards or paper-reading notes;
- unresolved questions for later lessons.

Avoid copying full conversational responses into notes. Rewrite them for revision and retrieval.
