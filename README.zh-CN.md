# Learn Anything

简体中文 | [English](README.md)

Learn Anything 是一个可复用的 Codex skill：它能够调研任意领域，并根据学习者的背景和目标，将调研结果组织成有来源支撑、个性化、可互动的系统课程。

它适合这样的需求：

- “带我系统学习计算神经科学。”
- “让我在一周内快速上手单细胞转录组分析。”
- “通过几篇里程碑论文带我进入扩散模型领域。”
- “我学过经济学基础，帮我诊断知识缺口并学习现代因果推断。”

这个 skill 会先调研并简要介绍领域，再给出几条真正不同的课程路线供学习者选择和修改。路线确认后，课程会有意识地分配详略：先快速补齐必要基础，对次要方向只讲原理和代表成果，对重点方向则深入模型原理、论文精读和实战。

## 为什么创建这个 skill

很多 AI 生成的课程，本质上只是被扩写的提纲：术语、工具、论文和注意事项很多，却没有真正帮助学习者形成直觉。

Learn Anything 采用不同的教学顺序：

1. 先讲清这个领域是什么、为什么重要、怎样发展到今天。
2. 在固定教学大纲前，先让学习者看到几条可选路线。
3. 只补齐所选路线真正需要的基础概念。
4. 主动安排详略：次要方向做高质量概览，重点方向结合理论、论文和实战深入学习。
5. 使用连续的因果叙事和贯穿案例讲解，避免堆砌彼此割裂的定义。
6. 每一讲结束后设置有目的的问题，检查复述、因果理解和知识迁移。
7. 根据用户的回答修正误解、补足缺口，并调整下一讲的深度和节奏。

它的目标不只是生成一份课程目录，而是帮助学习者建立一个真正能够用于解释、判断和实践的知识模型。

## 学习模式

Learn Anything 支持五种可以相互组合的模式：

| 模式 | 适合的目标 |
|---|---|
| 全面系统学习 | 建立完整、长期可用的领域知识体系 |
| 快速上手 | 沿最短但连贯的路线获得实用能力 |
| 项目导向 | 在真实项目需要某个概念之前及时学习 |
| 论文导向 | 通过里程碑论文和近期论文进入领域 |
| 查缺补漏 | 诊断已有知识，只重建薄弱或过时部分 |

## 工作方式

### 1. 系统调研领域

Agent 会建立一份精炼的证据地图，包括领域的核心问题、前置知识、历史转折、主要方法、代表成果、应用、开放问题和真实争议。对可能发生变化的近期信息，优先核查原始论文、官方文档和可靠综述。

### 2. 定制学习路线

完成简短的领域导览后，Agent 会提出两到四条在学习目标和“理论—论文—实战”配比上真正不同的路线，并询问哪些方向需要深入、哪些可以压缩，以及希望采用什么形式的实战。最终课程仍遵循知识依赖关系，但把时间集中在学习者真正关心的部分。

### 3. 以理解为目标讲课

每一讲从一个具体问题、现象、历史事件或代表成果开始。先建立直觉，再给出标准术语；公式只在能够提高理解精度时出现，并解释其中每一项的实际含义。

### 4. 通过互动调整课程

每讲结束通常设置三到四个问题，包括：

- 用学习者自己的语言进行复述；
- 解释原因或比较方法；
- 在新情境中迁移或预测；
- 必要时增加一个适合当前背景的进阶问题。

下一讲会从用户实际表现出的理解出发，而不是默认上一讲已经完全掌握。

### 5. 按需整理学习材料

对于长期课程，skill 可以维护课程笔记、文献索引，并把可以合法获取的论文或官方材料保存到本地。遇到付费墙或下载失败时，会明确标记需要人工获取的材料。

## 安装

将仓库克隆到 Codex 的个人 skills 目录。

### macOS 和 Linux

```bash
git clone https://github.com/liubingbenkun/learn-anything.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/research-and-learn"
```

### Windows PowerShell

```powershell
git clone https://github.com/liubingbenkun/learn-anything.git `
  "$env:USERPROFILE\.codex\skills\research-and-learn"
```

安装后新建一个 Codex 任务，使 Codex 重新发现该 skill。

## 使用示例

通过 `$research-and-learn` 显式调用：

```text
使用 $research-and-learn，带我全面系统学习计算神经科学。
我有机器学习基础，但神经科学基础较弱。
```

```text
使用 $research-and-learn，让我在一周内快速上手单细胞转录组分析。
重点理解方法选择，不需要进行环境部署。
```

```text
使用 $research-and-learn，通过五篇关键论文带我进入扩散模型领域。
在每篇论文之前补充所需的前置知识。
```

```text
使用 $research-and-learn，帮我复习因果推断需要的统计学。
先诊断我的掌握程度，已经熟悉的部分可以快速跳过。
```

当用户提出系统学习、快速进入一个领域、建立知识地图、定制课程或通过论文入门等需求时，该 skill 也可以被隐式触发。

## 设计原则

- 理解优先于覆盖面。
- 先讲概念，再讲工具。
- 先建立直觉，再进入形式化表达。
- 重要调研结论优先使用原始论文和权威来源。
- 使用完整、流畅的讲解，避免把提纲式碎片当作课程。
- 提问用于揭示学习者的认知模型，而不是考查冷知识。
- 先正面理解一项方法，再进入批判性阅读。
- 对尚无定论的问题诚实呈现不确定性和不同观点。
